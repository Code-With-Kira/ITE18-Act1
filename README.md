# Personal Profile Website

A responsive two-page personal profile website built with Nuxt 4, Vue 3, TypeScript, and Tailwind CSS.

## Pages

- `/` - homepage, welcome message, introduction, and profile card
- `/profile` - personal information, education, skills, interests, and hobbies

## Setup

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production

```bash
npm run build
npm run preview
```
